# TM-QC-101 — Protein Concentration by UV Absorbance (A280), FL-101 Drug Substance

**Fictitious Labs Inc.** · Version 2.0 · Effective 2025-11-03 · **SUPERSEDED by v2.1 on 2026-09-14** · Owner: Quality Control

## 1. Purpose

Determine the protein concentration of FL-101 drug substance by ultraviolet
absorbance at 280 nm.

## 2. Principle

FL-101 absorbs at 280 nm. Concentration is calculated from the absorbance
of a diluted sample against a formulation-buffer blank, using the method
extinction coefficient.

## 3. Parameters

| Item | Value |
|---|---|
| Wavelength | 280 nm |
| Path length | 1 cm |
| Dilution | 1:10 in formulation buffer |
| Blank | Formulation buffer |
| Replicates | 3 readings per preparation |
| Extinction coefficient (E 1%) | 1.42 |
| Reporting precision | One decimal place (mg/mL), per SOP-QA-002 |

## 4. Acceptance criterion

**8.5 – 11.5 mg/mL.**

## 5. Procedure (summary)

5.1 Equilibrate the sample to room temperature.
5.2 Mix gently.
5.3 Prepare the 1:10 dilution in formulation buffer.
5.4 Record the dilution on the worksheet (FRM-QC-101).
5.5 Blank the spectrophotometer with formulation buffer.
5.6 Read the diluted sample in triplicate.
5.7 Record all three readings on the raw data sheet.
5.8 Report the result per SOP-QA-002 (average of replicates, rounded once,
one decimal place).
