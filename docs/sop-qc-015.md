# SOP-QC-015 — QC Sample Accessioning, Thaw-Cycle Limits, and Expired Reagent Purge

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Purpose

This procedure describes how Quality Control accessions QC samples, controls freeze-thaw cycles for FL-101 aliquots, and purges expired reagents and buffers, under SOP-QC-006, Reference Standards and Laboratory Controls.
This procedure does not govern retention samples, which are governed by SOP-QC-005, Retention (Reserve) Samples, or stability samples, which are governed by SOP-QC-002, Stability Testing.

## 2. Accession a sample

1. Receive the sample.
2. Identify the sample by its QC sample ID.
3. Confirm the QC sample ID follows the format QC-<YYYY>-<NNNN>.
4. Note the example format QC-2026-0147 when checking the QC sample ID.
5. Open FL-EDMS, the company EDMS.
6. Create an accessioning entry for the sample on receipt.
7. Record the sample identity in the accessioning entry.
8. Record the sample source in the accessioning entry.
9. Record the sample quantity in the accessioning entry.
10. Record the sample storage condition in the accessioning entry.
11. Record the receipt date in the accessioning entry.
12. Check the accessioning entry records the sample identity.
13. Check the accessioning entry records the sample source.
14. Check the accessioning entry records the sample quantity.
15. Check the accessioning entry records the sample storage condition.
16. Check the accessioning entry records the receipt date.
17. Complete the accessioning entry following SOP-QA-001, Good Documentation Practices.
18. Handle a sample problem that may affect results under SOP-QA-010, Handling of Deviations.

## 3. Control freeze-thaw cycles

1. Identify the FL-101 aliquot before use.
2. Open the sample record for the aliquot.
3. Check the sample record for the freeze-thaw cycles already recorded.
4. Count one freeze-thaw cycle each time the aliquot is thawed after freezing.
5. Record the freeze-thaw cycle on the sample record.
6. Record each further freeze-thaw cycle on the sample record.
7. Complete each sample record entry following SOP-QA-001, Good Documentation Practices.
8. Check the total number of recorded freeze-thaw cycles before using the aliquot again.
9. Stop use of the aliquot when it has been subjected to 3 freeze-thaw cycles.
10. Do not subject an FL-101 aliquot to more than 3 freeze-thaw cycles.
11. Handle a freeze-thaw problem that may affect results under SOP-QA-010, Handling of Deviations.

## 4. Purge expired reagents

1. Review reagents for expired items each week.
2. Review buffers for expired items each week.
3. Identify each reagent that has expired.
4. Identify each buffer that has expired.
5. Tag each expired reagent.
6. Tag each expired buffer.
7. Remove each expired reagent from use on the same day it is identified as expired.
8. Remove each expired buffer from use on the same day it is identified as expired.
9. Record each expired reagent in FL-EDMS.
10. Record each expired buffer in FL-EDMS.
11. Complete each FL-EDMS record following SOP-QA-001, Good Documentation Practices.
12. Handle a reagent problem that may affect results under SOP-QA-010, Handling of Deviations.

## 5. Control of this procedure

1. Quality Assurance and the Quality Control Supervisor approve this procedure and each revision of it.
2. Make each revision through SOP-QA-004, Change Control.
