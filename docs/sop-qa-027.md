# SOP-QA-027 — Batch Record Content and Control

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Assurance

## 1. Purpose

Establish the required content and format of master batch records and batch production and control records, and how batch records are approved, issued, completed, and filed.

## 2. Scope

Applies to the master batch record and the batch production and control record for every batch of FL-101 drug substance manufactured at Fictitious Labs Inc., in the following functions: Manufacturing, Quality Assurance, Quality Control laboratory.

Does not cover the review of completed batch records or the release, rejection, or hold decision, which follow SOP-QA-006, Batch Record Review and Product Release. Does not cover labeling and packaging records, which follow SOP-QA-022, Labeling and Packaging Control.

## 3. Responsibilities

- **Manufacturing Supervisor**
  - Prepare the draft master batch record from the approved process description.
  - Confirm that the executed batch record issued for a batch is complete and legible before submitting it for review.
  - Resolve discrepancies that originate in Manufacturing under SOP-QA-001, Good Documentation Practices, or SOP-QA-010, Handling of Deviations.

- **Manufacturing Operator**
  - Record each production entry in the executed batch record at the time the step is performed.
  - Initial and date each significant step performed.

- **Quality Assurance**
  - Quality Assurance is the Quality Unit function designated for this procedure: Quality Assurance approves master batch records, assigns batch numbers, and issues executed batch records.
  - Verify that each issued executed batch record is an accurate reproduction of the effective master batch record.
  - Approve changes to the master batch record under SOP-QA-004, Change Control, before the changed record is used.

- **QA Manager**
  - Approve the initial issue of a master batch record for a new product or a new manufacturing process.

## 4. Procedure

### 4.1 Prepare the master batch record

1. Draft the master batch record from the approved process description for FL-101 drug substance.
2. State the identity of the product in the master batch record, including:
   - Product name and internal product code (FL-101).
   - Dosage form and strength description applicable to the drug substance, including the target protein concentration.
3. List every component to be used in manufacture, including:
   - The name and identifying code of each component.
   - The quantity of each component per batch, including any justified overage.
   - The identity of the approved cell bank from which the batch is produced.
4. State the theoretical yield of the batch in the master batch record.
5. State the acceptable percentage limits of theoretical yield at each applicable processing stage.
6. Describe each manufacturing step in the sequence in which it is performed, including:
   - The process parameters and their acceptable ranges for the step.
   - The major equipment and lines to be used.
   - Each in-process sampling point, with the test to be performed and its acceptance criterion or the governing test method.
   - The identity of each record generated at the step.
7. Compile the batch record list in the master batch record, naming every record that forms part of the completed batch record, including:
   - The executed batch record.
   - The laboratory records for every test in the approved FL-101 specification.
   - Labeling control records.
   - Records of investigations and sampling associated with the batch.
8. Submit the draft master batch record to Quality Assurance for approval.

### 4.2 Approve the master batch record

1. Review the draft master batch record against the approved process description and the approved FL-101 specification.
2. Approve the master batch record in FL-EDMS.
3. Obtain QA Manager approval for the initial issue of a master batch record for a new product or a new manufacturing process.
4. Make the approved master batch record effective in FL-EDMS under SOP-QA-003, Document Control.
5. Withdraw superseded versions of the master batch record from use under SOP-QA-003, Document Control.

### 4.3 Issue the executed batch record

1. Assign a unique batch number to the batch in FL-EDMS before manufacture begins.
2. Reproduce the effective master batch record exactly to create the executed batch record for the batch.
3. Verify the reproduction against the effective master batch record, including:
   - Every page is present and in sequence.
   - Every entry field, parameter, and limit matches the master batch record.
4. Sign and date the verification on the executed batch record.
5. Record the issuance in FL-EDMS, stating the batch number, the master batch record version issued, the number of pages, and the date of issue.
6. Print the batch number and the page number, stated as page X of Y, on every page of the executed batch record.

### 4.4 Complete the executed batch record

1. Record each entry at the time the corresponding step is performed, following SOP-QA-001, Good Documentation Practices.
2. Document the following for the batch in the executed batch record:
   - The dates on which each significant step was performed.
   - The identity of the major equipment and lines used.
   - The identity and quantity of each component and in-process material used, including lot numbers.
   - In-process and laboratory control results.
   - The results of inspections of the manufacturing and packaging areas.
   - The actual yield and the percentage of theoretical yield at each applicable processing stage.
   - A specimen or copy of the labeling applied to the batch containers.
   - Any investigation associated with the batch, by its FL-EDMS record number.
3. Initial and date each significant step you perform.
4. Obtain the initials of a second person for each weighing, measuring, and verification step the master batch record designates as requiring independent verification.
5. Correct any entry only as permitted by SOP-QA-001, Good Documentation Practices.
6. Report any discrepancy that cannot be resolved by documented correction to the Manufacturing Supervisor.

### 4.5 Close and file the completed batch record

1. Confirm that every record named in the batch record list is present in the completed batch record.
2. Confirm that no page of the executed batch record is missing and no required entry is blank.
3. Submit the completed batch record to Quality Assurance for review under SOP-QA-006, Batch Record Review and Product Release.
4. File the completed batch record in FL-EDMS under the batch number.

## 5. Records

Master batch records, current and superseded; batch record issuance records; and completed batch production and control records for each batch, retained under the retention requirements of SOP-QA-001, Good Documentation Practices.
