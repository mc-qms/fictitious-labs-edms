# SPEC-QC-101 — FL-101 Drug Substance Specification

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Product

FL-101, a monoclonal antibody drug substance derived from the approved CHO cell line, manufactured at Fictitious Labs Inc. and stored frozen at −20 °C ± 5 °C. This specification is established and maintained under SOP-QA-028, Specification Management. The retest period is assigned under SOP-QC-002, Stability Testing, and is not fixed by this specification.

## 2. Release specification

| Test | Procedure | Acceptance criterion |
|---|---|---|
| Appearance | Visual examination after thawing | Clear to slightly opalescent, colorless to pale yellow liquid, free from visible particles |
| Identity | Peptide mapping, validated procedure under SOP-QC-003 | Peptide map conforms to the FL-101 reference standard |
| Protein concentration | TM-QC-101, Protein Concentration by UV Absorbance (A280) | 9.0 – 11.0 mg/mL |
| Purity, size-exclusion chromatography | Validated procedure under SOP-QC-003 | Monomer ≥ 95.0% |
| Purity, CE-SDS (reduced) | Validated procedure under SOP-QC-003 | Main peak ≥ 90.0% |
| Bacterial endotoxin | Validated procedure under SOP-QC-003 | < 0.5 EU/mg |
| Bioburden | Validated procedure under SOP-QC-003, tested before sterilizing filtration | ≤ 10 CFU/100 mL |
| pH | Validated procedure under SOP-QC-003 | 5.5 – 6.5 |

## 3. Application

1. Apply every test in section 2 to each batch of FL-101 drug substance before release.
2. Perform bioburden testing on the bulk before the sterilizing filtration performed under SOP-QA-024, Aseptic Processing and Media Fills.
3. Report each result under SOP-QA-002, Reporting Numerical Values.
4. Refer any result outside its acceptance criterion for investigation under SOP-QA-012, Out-of-Specification (OOS) Investigation.
5. Review batch results against this specification as part of batch release under SOP-QA-006, Batch Record Review and Product Release.
