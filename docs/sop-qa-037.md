# SOP-QA-037 — Site Master File and Quality Manual Maintenance

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Assurance

## 1. Purpose

This procedure describes how the Site Master File and the Quality Manual are maintained, reviewed, and revised. It keeps both documents current so they describe the site and its quality system as they actually operate.

## 2. Scope

Applies to the Site Master File and the Quality Manual at Fictitious Labs Inc., a US-based biologics organization manufacturing monoclonal antibody drug substance in the United States, in the following functions: Quality Assurance, Document Control.

Does not cover the content of any individual standard operating procedure. Neither the Site Master File nor the Quality Manual replaces any SOP, and neither document is used in place of an SOP. Document control mechanics themselves, including numbering, formatting, issuance, and archiving, follow SOP-QA-003, Document Control.

## 3. Responsibilities

**Document Control**

- Maintain the Site Master File as a controlled document in FL-EDMS.
- Maintain the Quality Manual as a controlled document in FL-EDMS.
- Issue approved revisions in FL-EDMS.
- Retain superseded versions in FL-EDMS.

**Quality Assurance**

- Review the Site Master File at least annually.
- Review the Quality Manual at least annually.
- Review each document on any significant change to what it describes.
- Confirm that the content of each document matches current practice.

**QA Manager**

- Approve revisions to the Site Master File.
- Approve revisions to the Quality Manual.
- Confirm that a revision is complete before approval.

**Function heads**

- Provide current information about their function when requested.
- Review draft text that describes their function.
- Report changes in their function that may affect either document.

## 4. Procedure

### 4.1 Maintain the Site Master File

Document Control, a function within Quality Assurance, maintains the Site Master File in FL-EDMS on the EU GMP Part III and PIC/S pattern, adapted to a US site.

1. Describe the site and its general information.
2. Describe the quality management system.
3. Describe the premises.
4. Describe the equipment.
5. Describe the documentation system.
6. Describe production operations for monoclonal antibody drug substance.
7. Describe quality control operations.
8. Describe distribution arrangements.
9. Describe self-inspection arrangements.
10. Base the self-inspection content on the internal audit program under SOP-QA-007, Internal Audit.
11. Keep the text at a general descriptive level.
12. Refer to the SOP system for detailed requirements.
13. Update the draft text when source information changes.
14. Provide the current approved version to inspectors as the site general information document during inspection hosting.

### 4.2 Maintain the Quality Manual

Document Control, a function within Quality Assurance, maintains the Quality Manual in FL-EDMS as a controlled reference document.

1. State the quality policy.
2. Describe the structure of the quality system.
3. Describe the structure by reference to the SOP system.
4. List the main elements of the quality system.
5. Identify the SOP or SOP group that covers each element.
6. Avoid duplicating the text of any SOP.
7. Avoid restating requirements that are set in an SOP.
8. Update the draft text when the quality policy changes.
9. Update the draft text when the structure of the quality system changes.
10. Confirm that each reference to the SOP system is current.
11. Confirm that no section conflicts with the SOP it references.
12. Hold the revised draft for review under Section 4.3.

### 4.3 Review and approve revisions

Quality Assurance reviews each document at least annually and on any significant change to what it describes.

1. Schedule the annual review of the Site Master File.
2. Schedule the annual review of the Quality Manual.
3. Start an additional review when a significant change occurs.
4. Request current information from the relevant function heads.
5. Compare the current text against current practice.
6. Mark each passage that is no longer accurate.
7. Draft replacement text for each marked passage.
8. Check the draft against the source information provided.
9. Circulate the draft to the contributing function heads.
10. Resolve each comment received on the draft.
11. Process the revision through SOP-QA-004, Change Control.
12. Submit the final draft to the QA Manager.
13. Record the QA Manager approval in FL-EDMS.
14. Issue the approved version through SOP-QA-003, Document Control.
15. Withdraw the superseded version from general use in FL-EDMS.
16. Follow SOP-QA-001, Good Documentation Practices, for each entry made during the review.

## 5. Records

Records generated under this procedure include review records for the Site Master File, review records for the Quality Manual, change records for revisions, and approval records in FL-EDMS.

Document Control keeps the current approved version of each document in FL-EDMS and keeps superseded versions available for reference.

Contributors keep the source information they provide until the revision that uses it has been approved.

All records generated under this procedure are retained under the retention requirements of SOP-QA-001, Good Documentation Practices.
