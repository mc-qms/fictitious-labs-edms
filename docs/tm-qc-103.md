# TM-QC-103 — Purity by Size-Exclusion Chromatography, FL-101 Drug Substance

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Purpose

This method determines the purity of FL-101 drug substance as the
percent monomer by size-exclusion chromatography (SEC).

## 2. Principle

SEC separates the FL-101 monomer from high-molecular-weight species
(aggregates) and low-molecular-weight species (fragments) by
hydrodynamic size. Peak areas at 280 nm give the monomer as a percent
of total peak area.

## 3. Parameters

| Item | Value |
| --- | --- |
| Column | Size-exclusion column, 7.8 mm × 300 mm |
| Mobile phase | 100 mmol/L sodium phosphate, 200 mmol/L sodium chloride, pH 6.8 |
| Flow rate | 0.5 mL/min |
| Detection | 280 nm |
| System suitability material | FL-101 reference standard, injected before the samples |
| Sample injections | One injection per sample |
| Reporting precision | One decimal place (percent), per SOP-QA-002 |

## 4. System suitability

1. Resolution between the monomer peak and the nearest
   high-molecular-weight peak is ≥ 1.0.
2. Monomer peak tailing factor is ≤ 2.0.
3. Three reference standard injections give a relative standard
   deviation of monomer percent of ≤ 1.0%.

A run that does not meet every criterion in this section yields no
reportable result.

## 5. Procedure (summary)

5.1 Equilibrate the column with mobile phase.
5.2 Inject the FL-101 reference standard three times.
5.3 Evaluate system suitability against section 4.
5.4 Equilibrate the sample to room temperature.
5.5 Mix the sample gently.
5.6 Inject the sample once.
5.7 Integrate the monomer, high-molecular-weight, and
    low-molecular-weight peaks.
5.8 Record all peak areas on the raw data record.

## 6. Result and reporting

Monomer percent = monomer peak area divided by total peak area,
multiplied by 100. The reported result is the monomer percent,
reported to one decimal place per SOP-QA-002. Cite the reference
standard identifier in the test record per SOP-QC-006. Record per
SOP-QA-001.

Acceptance of the reported result is per SPEC-101, FL-101 Drug
Substance Specification. This method states no acceptance criterion
for the product.
