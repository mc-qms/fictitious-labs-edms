# TM-QC-102 — Identity by Peptide Mapping, FL-101 Drug Substance

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Purpose

This method establishes the identity of FL-101 drug substance by
tryptic peptide mapping, by comparison with the FL-101 reference
standard.

## 2. Principle

FL-101 is denatured, reduced, alkylated, and digested with trypsin.
The peptides are separated by reversed-phase HPLC with UV detection.
The resulting peptide map reflects the primary structure, and identity
is established by correspondence with the map of the FL-101 reference
standard digested and run in parallel.

## 3. Parameters

| Item | Value |
| --- | --- |
| Sample | FL-101 drug substance |
| Comparator | FL-101 reference standard, digested and run in parallel with every sample set |
| Enzyme | Trypsin |
| Separation | Reversed-phase HPLC, UV detection |
| Designated peaks | The six most prominent peaks of the reference map, designated in elution order |
| Peak match window | Relative retention time within ±2% of the reference value |
| New peak reporting threshold | 1.0% of total peak area |

## 4. System suitability

1. All designated peaks are present in the reference standard map.
2. The resolution between the closest-eluting designated pair is
   ≥ 1.0.

A run that does not meet every criterion in this section yields no
reportable result.

## 5. Procedure (summary)

5.1 Equilibrate sample and reference standard to room temperature.

5.2 Prepare the sample digest (denature, reduce, alkylate, digest
with trypsin).

5.3 Prepare the reference standard digest in parallel by the same
steps.

5.4 Prepare a blank digest containing no protein.

5.5 Inject the blank digest.

5.6 Inject the reference standard digest.

5.7 Inject the sample digest.

5.8 Identify the designated peaks in the reference map.

5.9 Compare the sample map with the reference map peak by peak.

5.10 Record each designated peak as present or absent and each new
peak at or above the reporting threshold.

## 6. Result and reporting

The result is the correspondence of the sample map with the reference
map, reported as conforms or does not conform, with the peak-by-peak
comparison recorded in the test record. Cite the reference standard
identifier in the test record per SOP-QC-006. Record and report per
SOP-QA-001 and SOP-QA-002.

Acceptance of the reported result is per SPEC-101, FL-101 Drug
Substance Specification. This method states no acceptance criterion
for the product.
