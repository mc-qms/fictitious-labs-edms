# TM-QC-107 — pH Measurement, FL-101 Drug Substance

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Purpose

This method measures the pH of FL-101 drug substance
potentiometrically, following USP <791>, pH.

## 2. Principle

The pH is measured with a combination glass electrode. The
potential difference between the measuring and reference elements
is proportional to hydrogen ion activity and is read directly
from the calibrated meter.

## 3. Parameters

| Item | Value |
| --- | --- |
| Instrument | pH meter with combination glass electrode |
| Calibration buffers | pH 4.00, 7.00, and 10.00, three-point calibration |
| Daily calibration | Performed before first use under SOP-QC-014, Bench Instrument Operation and Daily Checks |
| Sample condition | Thawed and equilibrated to 25 °C ± 2 °C |
| Check buffer | Independent pH 7.00 buffer from a second lot |
| Reporting precision | Two decimal places, per SOP-QA-002 |

## 4. System suitability

1. The electrode slope from the daily calibration is 95.0–105.0%.
2. The independent pH 7.00 check buffer reads within ±0.05 pH
   units of 7.00.

A measurement session that does not meet every criterion in this
section yields no reportable result.

## 5. Procedure (summary)

5.1 Thaw the sample.
5.2 Equilibrate the sample to 25 °C ± 2 °C.
5.3 Confirm the daily calibration has been performed under
    SOP-QC-014.
5.4 Read the electrode slope from the calibration record.
5.5 Measure the independent pH 7.00 check buffer.
5.6 Rinse the electrode with purified water.
5.7 Immerse the electrode in the sample.
5.8 Record the reading exactly as displayed when it is stable.
5.9 Return the probe to storage solution after use (per
    SOP-QC-014).

## 6. Result and reporting

The reported result is the recorded reading, reported to two
decimal places per SOP-QA-002. Per SOP-QA-002, a value read from
an instrument display is transcribed exactly as displayed.
Record per SOP-QA-001 and SOP-QC-006.

Acceptance of the reported result is per SPEC-101, FL-101
Drug Substance Specification. This method states no acceptance
criterion for the product.
