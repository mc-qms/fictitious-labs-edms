# TM-QC-104 — Purity by CE-SDS (Reduced), FL-101 Drug Substance

**Fictitious Labs Inc.** · Version 1.0 · Effective 2026-03-02 · Owner: Quality Control

## 1. Purpose

This method determines the purity of FL-101 drug substance as the
percent main peak by capillary electrophoresis with sodium dodecyl
sulfate under reducing conditions (CE-SDS, reduced).

## 2. Principle

The sample is denatured with SDS and reduced with
2-mercaptoethanol, separating the antibody into its light and heavy
chains. Capillary electrophoresis in an SDS gel buffer separates
the chains and any fragments or non-reduced species by size. The
main peak is the sum of the light-chain and heavy-chain peaks,
expressed as a percent of total corrected peak area.

## 3. Parameters

| Item | Value |
| --- | --- |
| Sample preparation | Denature in SDS sample buffer containing 2-mercaptoethanol and an internal standard |
| Heating | 100 °C for 3 minutes |
| Comparator | FL-101 reference standard, prepared by the same steps |
| Peak areas | Corrected area: peak area divided by migration time |
| Reporting precision | One decimal place (percent), per SOP-QA-002 |

## 4. System suitability

1. Resolution between the light-chain and heavy-chain peaks is
   ≥ 1.5.
2. Three reference standard preparations give a relative standard
   deviation of main peak corrected area percent of ≤ 2.0%.

A run that does not meet every criterion in this section yields no
reportable result.

## 5. Procedure (summary)

5.1 Equilibrate the sample and the reference standard to room
temperature.

5.2 Add SDS sample buffer containing 2-mercaptoethanol and the
internal standard to each.

5.3 Heat each preparation at 100 °C for 3 minutes.

5.4 Cool each preparation to room temperature.

5.5 Prepare the reference standard three times by the same steps.

5.6 Inject the reference standard preparations.

5.7 Evaluate system suitability against section 4.

5.8 Inject the sample preparation.

5.9 Record the migration times and peak areas on the raw data
record.

## 6. Result and reporting

Main peak percent = the sum of the light-chain and heavy-chain
corrected areas divided by the total corrected area, multiplied by
100. The reported result is the main peak percent, reported to one
decimal place per SOP-QA-002. Cite the reference standard
identifier in the test record per SOP-QC-006. Record per
SOP-QA-001.

Acceptance of the reported result is per SPEC-QC-101, FL-101 Drug
Substance Specification. This method states no acceptance criterion
for the product.
